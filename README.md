# Hey, I'm Jordan Clifford

I recently graduated from Arizona State University with a B.S. in Computer Science, focused on software engineering, backend systems, data engineering, and applied machine learning.

I like building projects where raw data turns into something useful: pipelines, APIs, dashboards, simulations, and tools that people can actually interact with.

## Projects to Check Out

### Courtside Modeling: NBA Machine Learning Simulator

[View repository](https://github.com/jordanjasonclifford/nba_ml)

An interactive NBA simulation app that uses warehouse data and machine learning to model games, player box scores, play-by-play flow, overtime, and the 2025-26 playoff/play-in bracket.

Built with Python, Streamlit, Flask, Pandas, NumPy, PostgreSQL-style modeling, and scikit-learn.

### NBA Data Engineering + Power BI

[View repository](https://github.com/jordanjasonclifford/nba_data_engineering)

The data warehouse and reporting layer behind Courtside Modeling. This project handles the ETL pipeline, cleaned basketball datasets, warehouse structure, and Power BI analytics side of the NBA portfolio.

Built with Python, PostgreSQL, ETL workflows, and Power BI.

### SalesNest: Self-Improving AI Call Agent

[View repository](https://github.com/jordanjasonclifford/call_center_agent)

An AI sales agent that runs voice cold calls, handles objections, and improves its script through a feedback loop. It uses a two-stage LLM pipeline to analyze weak points and optimize future responses.

Built with Python, LLM workflows, faster-whisper, edge-tts, and a lightweight web demo.

### Multi-Modal Route Optimization with Hybrid Travel

[View repository](https://github.com/jordanjasonclifford/Multi-Modal-Route-Optimization-with-Hybrid-Travel)

An NSF REU smart cities research project that compares driving, biking, and transit routes across 24k+ samples using Google Maps API data and machine learning. The project also explores reinforcement learning for travel-mode selection by time of day and location.

Built with Python, Google Maps API, machine learning, and reinforcement learning.

### Modular AI Camera System

[View poster](https://www.jordanclifford.dev/edge_presentation.pdf)

A capstone project for ARED Group Inc. focused on modular, edge-deployed AI video analytics for real-time monitoring and security insights from live camera streams.

Built with ONNX Runtime, microservices, Docker, BalenaOS, and CPU-only edge inference.
